# منصة بُعد التمكين — Buad Platform

نظام إدارة مشاريع وفعاليات متكامل مبني على تقنية HTML/CSS/JS بدون خادم خلفي.

## الميزات
- لوحة تحكم رئيسية بشريط جانبي (الرئيسية، المشاريع، العملاء، المالية)
- إدارة مشاريع متعددة من ملف واحد
- نموذج مشروع كامل (ملتقى صيادلة عسير) يمكن نسخه لأي مشروع جديد
- غلاف مشروع احترافي قابل للتعديل (شعار الجهة، الحالة، البيانات السريعة)
- ربط مالي كامل: الميزانية ↔ العقد ↔ المتابعة الفعلية
- تصدير العقد والتوزيع المالي كـ PDF
- يعمل بدون إنترنت (offline-first)

## الملفات
| الملف | الوصف |
|-------|--------|
| `index.html` | لوحة التحكم الرئيسية — نقطة الدخول |
| `project-template.html` | نموذج المشروع الكامل (مستقل) |

## النشر
الموقع ثابت (static site) — يعمل على أي خادم أو Netlify مباشرة.

## التطوير
بُعد التمكين للخدمات التنفيذية
