# اختبارات الطرف إلى الطرف (e2e)

تشغّل المنصة كاملة: الـWorker مع الواجهة المبنية وقاعدة D1 محلية جديدة. ثم تقود Chromium بمقاسَي الحاسوب والجوال.

```bash
pnpm build                                  # الواجهة المبنية يخدمها الـWorker
pnpm --filter @buad/e2e exec playwright install chromium   # مرة واحدة
pnpm --filter @buad/e2e e2e                 # يشغّل الخادم على 8788 ثم الاختبارات
```

- **الأسرار**: `serve.sh` يمرّر أسراراً للاختبار فقط عبر `--var`، فلا يمسّ `.dev.vars`.
- **القاعدة**: تُبنى من الهجرات في `e2e/.state` وتُحذف عند كل تشغيل.
- **البيانات**: كل اختبار ينشئ بياناته بأسماء فريدة، فلا بيانات ثابتة ولا أرقام مالية حقيقية.
